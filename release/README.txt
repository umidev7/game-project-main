NEON RIFT

1. Download the player ZIP and extract it.
2. Double-click NeonRift.exe.
3. Enter the server address shown by your host, then select CONNECT.

For a local game, use 127.0.0.1:8765 when the server is running on this computer.

Controls:
- WASD or arrow keys: move
- Space: fire
- Esc: pause or resume
- Enter: start or restart
- Mouse: use menu buttons

To close the game, press the window's X button.
